PUBLICAÇÃO EXTERNA — USO PESSOAL DA ARYANE

Escolha confirmada: hospedagem gratuita e Google Sheets para os registros.
Serviço previsto: Streamlit Community Cloud, com endereço próprio em streamlit.app.
O aplicativo não usa ChatGPT, login OpenAI, API OpenAI ou hospedagem Sites.
Não foi criada uma publicação externa nesta etapa: é necessário concluir as autorizações abaixo.

1. GITHUB E STREAMLIT — UMA VEZ

Conecte o GitHub para que seja possível criar o repositório e enviar o projeto.
No Streamlit Community Cloud, vincule esse repositório e selecione streamlit_app.py.
Essa entrada impede o uso de dados temporários na hospedagem.
Use Python 3.11 ou superior. O requirements.txt já contém as bibliotecas.
Deixe o visitante chegar à tela do próprio aplicativo, protegida por login/senha,
sem ativar uma segunda exigência de login Google/Streamlit para visualizar o app.
O código pode permanecer em um repositório privado.

2. GOOGLE SHEETS — UMA VEZ

A base já foi criada, com as quatro abas e os dados iniciais:
https://docs.google.com/spreadsheets/d/12GKooqAJfh4OjPjFITPJ_fmJedkQhwdsVXJzSQt6bP0/edit

Em um projeto Google Cloud sob sua administração:
- Habilite Google Sheets API.
- Crie uma conta de serviço para o aplicativo.
- Gere sua chave JSON e guarde-a como credencial privada.
- Compartilhe somente essa planilha, como Editor, com o client_email da conta.
- Copie os campos da chave para [gcp_service_account] nos Secrets da hospedagem.

A conta de serviço acessa a planilha pelo servidor. Aryane não precisa entrar
na conta Google todos os dias para usar o aplicativo.
Não torne a planilha pública para tentar dispensar essa configuração.

3. CONFIGURAÇÃO DA HOSPEDAGEM

Use o exemplo completo em .streamlit/secrets.toml, com estas diferenças:
- production_mode = true
- authentication_required = true
- auth_cookie_key = uma chave aleatória privada e estável, de pelo menos 32 caracteres
- Preencha todo o bloco [gcp_service_account].

Gere a chave de cookie uma única vez:
python -c "import secrets; print(secrets.token_urlsafe(48))"

Não troque a chave a cada execução ou deploy. Trocar a chave encerra os acessos
lembrados e exige entrar novamente. Ao trocar a senha, os cookies antigos
também deixam de valer. Não publique a chave no GitHub nem no código do navegador.

4. USO DIÁRIO

Abra o link do aplicativo, informe o login Aryane e a senha solicitada e mantenha
marcada a opção Manter conectado neste navegador. O acesso é lembrado por até
365 dias, exceto ao sair, limpar os cookies ou trocar a senha. Outros navegadores,
perfis e aparelhos precisam do primeiro login separadamente.

As OPs e os saldos ficam no Google Sheets e sobrevivem ao fechamento do navegador
e ao reinício do serviço. As simulações são recalculadas. O registro de eventos
da tela de Qualidade continua sendo o histórico da sessão, não uma auditoria
permanente. Nenhum dado real foi digitado nem movimentado na base nesta etapa.

5. VERIFICAÇÃO ANTES DO USO

- A empresa precisa permitir os domínios streamlit.app e os serviços Google usados.
  Ausência de ligação ao ChatGPT não garante que a rede da empresa permita qualquer site.
- Confirme GOOGLE SHEETS SINCRONIZADO no topo.
- Cadastre uma OP de teste, feche o navegador e entre novamente.
- Confira que a OP continua presente e que o login foi lembrado.
- Apague ou corrija o registro de teste na planilha, conforme sua rotina.
